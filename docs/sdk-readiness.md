# SDK readiness

The supported server SDKs are TypeScript (`@ductape/sdk`) and NestJS (`@ductape/nestjs`).

## Summary

| | TypeScript | NestJS |
|---|------------|--------|
| **Package** | `@ductape/sdk` | `@ductape/nestjs` |
| **Release** | npm | npm |
| **Runtime** | Full SDK and executors | NestJS modules, decorators, and injectable SDK services |
